# Data: Dialogues on Democracy

De-identified, analysis-ready data for Study 1 and Study 2. The shareable stage-0 raw dataset `raw/original_dfs_shareable.RData` is included to enable reproducing `scripts/01_cleaning.Rmd` from scratch; un-anonymized raw Qualtrics exports are not shared and remain gitignored.

## Files

- **`clean_dfs.RData`**: output of `scripts/01_cleaning.Rmd`. Data frames: `df_all` (all Study 1 and 2 survey records),
  `df_trim` / `df_trim_2` (Study 1 / Study 2 after screening and baseline exclusions), and the analytic samples
  `df_consp` (Study 1, *n* = 1,215), `df_consp_2` (Study 2, *n* = 633) and `df_both` (*N* = 1,848), which add the NLP coding
  of the open-ended claim as an election conspiracy. Variable descriptions for the primary aggregate outcomes are detailed below.
- **`df_convosfin.xlsx`**: All 1,655 completed conversations (all participants who completed a full 3-turn dialogue across Study 1 and Study 2) with GPT-coded claim themes (`ConspiracyTheme_*`) and conversation-level evidence counts (`EvidenceFreq`), produced by `scripts/02a_llm_theme_coding.R`. The slimmed format retains only conversation text and NLP response variables (30 clean columns).
- **`df_strategy_coded.RData`**, **`df_strategy_coded_checkpoint.rds`**, **`df_nuance_clearclaim_checkpoint.rds`**: GPT codes of each
  conversation turn (persuasion strategies, argument quality, nuance), from `02b_llm_strategy_coding.R` and `02c_llm_nuance_coding.R`; `df_strategy_coded.RData` is written by `08_results_strategies.Rmd`.
- **`threat_all_statement_nlp.xlsx`**: NLP classification of participants' initial statements (conspiracy classification, claim topic, emotional tone, threat type, target of threat, and language features), read by `01_cleaning.Rmd`.

## Primary Aggregate Outcome Measures

The primary statistical models across the manuscript and supplement (`05_results_effects.Rmd`, `05b_effects_bayesian.R`, `07_results_belief_level.Rmd`, `08_results_strategies.Rmd`, `09_heterogeneity_forests.Rmd`, `10_mediation.Rmd`) and manuscript figures analyze the **8 aggregate outcome variables** (`dvs_post` in `4-analysis/R/setup.R`). These correspond directly to the measures described in the manuscript and the supplement measures table (Table S1 / `@tbl-measures`).

While individual survey items are retained in `clean_dfs.RData` for complete replication transparency, the analyses intentionally focus on these composite and key construct aggregates to reduce measurement error and assess generalizability across specific and broad conspiratorial beliefs.

## What was removed

These columns are not in the released files:

1. **Quasi-identifiers & metadata**: ZIP code, household income, region and ethnicity (Lucid panel profile fields), browser, browser version, operating system and screen resolution, start, end and recorded timestamps, conversation creation time, birth year (`Age` is kept), free-text end-of-survey comments, `UserLanguage`, `Captcha`, `nicks`, `Q_TerminateFlag`, and model string metadata.
2. **Intermediate survey artifacts & timers**: Raw page click timers (`q1_timing_*`, `q2_timing_*`, `q3_timing_*`), raw question text inputs (`Q5`, `Q7`, `Q9`), raw conversation text chunks (`chathistory1`–`4`), bot-screener items (`screener3_*`), and duplicate raw conversation fragments (`userResponse_pt1`, `userResponse_pt2`, `userResponse`, `userSecondResponse`, `userThirdResponse`, `GPTResponse`, `GPTResponse2`, `GPTResponse3`, `userResponse_5`, `GPTResponse_5`, which were merged into structured `userResponse_1:4` and `GPTResponse_1:4`).
3. **Prompt scaffolding, uncleaned text & sensitive extractions**: LLM prompt strings (`activeConditionNumber`, `embedsystemMessage`, `ChatbotPromptTemplate`, `systemMessageTemplate`), raw uncleaned demographic strings (`education`, `hispanic`, `political_party`, raw `age`, `gender`, `Gender`, `DemRep_C.text`, `PartyAffil.text`, `PartyReg.text`, `VoteMethod.text`), open-ended text inputs (`MagicPill_5_TEXT`), unreviewed sensitive values extractions (`principles`), "Other (specify)" text dumps, and unused media checklist text fields (`NewsSources_*.text`).
4. **Broken values metrics**: The 11 Schwartz values scale scores from early exploratory NLP coding that contained format splitting errors (`Power`, `Achievement`, `Hedonism`, `Stimulation`, `Self_Direction`, `Universalism`, `Benevolence`, `Tradition`, `Conformity`, `Security`, `DominantValue`). Categorical keyword values measures (`ValuesCategory`, `PrimaryValuesCategory`) are retained.

None of these removed variables is used by the downstream analysis scripts. `01_cleaning.Rmd` (chunk "deidentify for release") removes them before saving `clean_dfs.RData`.

The Qualtrics `ResponseId` is retained because the coded-conversation files and the Shiny app are keyed on it. Open-ended responses and conversation text are included verbatim.
