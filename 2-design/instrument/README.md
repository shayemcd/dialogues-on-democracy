# Survey Instruments: Dialogues on Democracy (Studies 1 & 2)

This folder contains the survey instrument exports, preview documents, and build specifications for Study 1 and Study 2.

> [!NOTE]
> All Qualtrics Survey Format (`.qsf`) files in this directory are sanitized for public dissemination with all private API keys replaced with placeholders (`YOUR_OPENAI_API_KEY_HERE`).

## Survey Files
- **Study 1** (3 message conditions x 2 interfaces):
  - `Study1_Survey.qsf`: Full Qualtrics survey flow and JavaScript blocks.
  - `Study1_Survey_Preview.docx`: Survey preview export.
- **Study 2** (belief-tailored, adversarial dialogue, cats & dogs control; chat interface):
  - `Study2_Survey.qsf`: Full Qualtrics survey flow and JavaScript blocks.
  - `Study2_Survey_Preview.docx`: Survey preview export.

## Specifications
- `instrument-spec.md`: Detailed block structure, screening logic, and prompt engineering specifications.
